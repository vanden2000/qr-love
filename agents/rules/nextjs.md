# QR Love UI Rules

Design mobile-first.

Primary widths:

375px
390px
430px

Visual direction:

- romantic
- elegant
- minimal
- cinematic
- modern

Avoid:

- excessive gradients
- rainbow colors
- unnecessary cards
- excessive emojis
- cluttered layouts

Important touch targets should be at least 44px tall.

The gift experience should feel immersive.

Use responsive layouts for desktop, but mobile is the primary experience.
